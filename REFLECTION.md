# Project Reflection

## Maze Symbols

I used clear symbols to make the maze easier to understand:

- S represents the starting point.
- E represents the ending point.
- # represents a wall.
- . represents an empty cell.
- * represents the path found by BFS.

## What surprised me?

I learned that BFS can find the shortest path in an unweighted graph by exploring nodes level by level.

I was also surprised by how a queue helps organize the search process.

## What did I learn?

- How to represent a maze as a graph.
- How BFS explores neighboring cells.
- How to use a queue and a visited set.
- How to write unit tests in Python.
- How to analyze time and space complexity.

## What would I do next?

I would like to improve the project by adding a graphical interface to display the maze and visualize the solution path.
